# 1. Front door

This is **Contoso Model Hive**, a model Hive: like a model home, everything is furnished so you can walk through, but nobody lives here. Synthetic model: fictional people and devices, signed with public test keys that anyone can re-derive. Never use them for real data.

A Hive is one portable organism made of sovereign streams. Each person or device writes only its own signed stream. Nothing else is stored as authority: who belongs, which rules apply and what everything means are **derived** from the signed frames, the same way on every device.
